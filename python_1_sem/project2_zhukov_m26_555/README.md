# Primitive DB

Primitive DB — простая консольная база данных на Python.

Реализованы создание и удаление таблиц, CRUD-операции, фильтрация, проверка типов, подтверждение удаления и кэширование выборок. Метаданные и записи сохраняются в JSON.

Поддерживаемые типы данных:

- `int` — целое число
- `str` — строка
- `bool` — логическое значение

## Установка
```
poetry install
```

## Запуск и проверка

```sh
poetry run database # или make run
make lint
```

Требуются Python 3.10+ и Poetry.

## Управление таблицами

После запуска программа переходит в интерактивный режим:

```text
***Процесс работы с таблицей***

Функции:
<command> create_table <имя_таблицы> <столбец1:тип> .. - создать таблицу
<command> list_tables - показать список всех таблиц
<command> drop_table <имя_таблицы> - удалить таблицу

Общие команды:
<command> exit - выход из программы
<command> help - справочная информация

>>>Введите команду:
```

### `create_table`

Создаёт новую таблицу.

Синтаксис:

```text
create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...
```

Пример:

```text
create_table users name:str age:int is_active:bool
```

Результат:

```text
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
```

Если пользователь не указал колонку `ID`, она автоматически добавляется в начало таблицы с типом `int`.

Например:

```text
create_table products name:str price:int
```

будет создана таблица со следующей структурой:

```text
ID:int, name:str, price:int
```

Колонку `ID` можно указать явно, но только с типом `int`.

Создать две таблицы с одинаковым именем нельзя:

```text
create_table users name:str
```

Если `users` уже существует:

```text
Ошибка: Таблица "users" уже существует.
```

### `list_tables`

Показывает список всех созданных таблиц.

Синтаксис:

```text
list_tables
```

Пример:

```text
>>>Введите команду: list_tables
- users
- products
- orders
```

Если таблиц ещё нет:

```text
Таблиц нет.
```

### `drop_table`

Удаляет таблицу из базы данных.

Синтаксис:

```text
drop_table <имя_таблицы>
```

Пример:

```text
drop_table users
```

Результат:

```text
Таблица "users" успешно удалена.
```

Если указанной таблицы не существует:

```text
drop_table products
```

Результат:

```text
Ошибка: Таблица "products" не существует.
```

### `help`

Выводит справку по доступным командам.

Синтаксис:

```text
help
```

Результат:

```text
***Процесс работы с таблицей***

Функции:
<command> create_table <имя_таблицы> <столбец1:тип> .. - создать таблицу
<command> list_tables - показать список всех таблиц
<command> drop_table <имя_таблицы> - удалить таблицу

Общие команды:
<command> exit - выход из программы
<command> help - справочная информация
```

### `exit`

Завершает работу с базой данных.

Синтаксис:

```text
exit
```

## Обработка ошибок

Если введена неизвестная команда:

```text
>>>Введите команду: create
Функции create нет. Попробуйте снова.
```

Если передано некорректное значение:

```text
>>>Введите команду: create_table users age:float
Некорректное значение: age:float. Попробуйте снова.
```

Поддерживаются только следующие типы:

```text
int
str
bool
```

## Хранение метаданных

Информация о созданных таблицах сохраняется в файл:

```text
db_meta.json
```

Пример содержимого:

```json
{
    "users": {
        "columns": [
            {
                "name": "ID",
                "type": "int"
            },
            {
                "name": "name",
                "type": "str"
            },
            {
                "name": "age",
                "type": "int"
            },
            {
                "name": "is_active",
                "type": "bool"
            }
        ]
    }
}
```

Благодаря сохранению метаданных созданные таблицы остаются доступными после завершения и повторного запуска программы.

## Структура проекта

```text
src/
└── primitive_db/
    ├── __init__.py
    ├── main.py
    ├── core.py
    ├── engine.py
    ├── utils.py
    ├── parser.py
    ├── decorators.py
    └── constants.py
```

- `core.py` — основная логика управления таблицами.
- `engine.py` — обработка команд пользователя и основной цикл программы.
- `utils.py` — загрузка и сохранение метаданных.
- `main.py` — точка входа в приложение.
- `db_meta.json` — метаданные созданных таблиц.
  

## CRUD-операции

После создания таблиц база данных позволяет выполнять основные CRUD-операции с данными:

- `insert` — добавление записей;
- `select` — получение записей;
- `update` — изменение записей;
- `delete` — удаление записей;
- `info` — получение информации о таблице.

Данные каждой таблицы хранятся в отдельном JSON-файле в директории `data/`.

Например, данные таблицы `users` хранятся в:

```text id="xbky9p"
data/users.json
```

### Добавление записи — `insert`

Команда `insert` добавляет новую запись в указанную таблицу.

Синтаксис:

```text id="edr2ke"
insert into <имя_таблицы> values (<значение1>, <значение2>, ...)
```

Значение для столбца `ID` указывать не нужно. Оно генерируется автоматически.

Например, для таблицы:

```text id="h60tvw"
ID:int, name:str, age:int, is_active:bool
```

команда:

```text id="k9x8ds"
insert into users values ("Sergei", 28, true)
```

создаст запись:

```text id="m4j0zo"
ID=1, name="Sergei", age=28, is_active=True
```

Результат:

```text id="5sw2kv"
Запись с ID=1 успешно добавлена в таблицу "users".
```

Количество переданных значений должно соответствовать количеству столбцов таблицы без учёта `ID`. Тип каждого значения должен соответствовать типу соответствующего столбца.

Строковые значения необходимо указывать в двойных кавычках:

```text id="n97ghd"
"Sergei"
```

Логические значения:

```text id="khmvj7"
true
false
```

### Получение всех записей — `select`

Для получения всех записей таблицы используется команда:

```text id="ovdk2j"
select from <имя_таблицы>
```

Пример:

```text id="bxeylw"
select from users
```

Результат выводится в табличном формате:

```text id="49e17v"
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
| 2  |  Ivan  |  35 |   False   |
+----+--------+-----+-----------+
```

### Получение записей по условию — `select ... where`

Для фильтрации записей используется условие `where`.

Синтаксис:

```text id="f0f1cb"
select from <имя_таблицы> where <столбец> = <значение>
```

Пример:

```text id="t3r2re"
select from users where age = 28
```

Результат:

```text id="tzeg0i"
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+
```

По строковому значению:

```text id="y46xbv"
select from users where name = "Sergei"
```

По логическому значению:

```text id="d07ik8"
select from users where is_active = true
```

### Обновление записи — `update`

Команда `update` изменяет значения существующих записей, подходящих под условие `where`.

Синтаксис:

```text id="73fc33"
update <имя_таблицы> set <столбец> = <новое_значение> where <столбец> = <значение>
```

Пример:

```text id="96omkm"
update users set age = 29 where name = "Sergei"
```

Результат:

```text id="t92c6h"
Запись с ID=1 в таблице "users" успешно обновлена.
```

После выполнения команды:

```text id="1xj1xg"
select from users where name = "Sergei"
```

будет выведено:

```text id="7c1e9r"
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  29 |    True   |
+----+--------+-----+-----------+
```

Тип нового значения должен соответствовать типу столбца.

### Удаление записи — `delete`

Команда `delete` удаляет записи, соответствующие условию `where`.

Синтаксис:

```text id="8rwncf"
delete from <имя_таблицы> where <столбец> = <значение>
```

Пример:

```text id="m4cqgd"
delete from users where ID = 1
```

Результат:

```text id="m0u6pa"
Запись с ID=1 успешно удалена из таблицы "users".
```

Можно использовать и другие столбцы:

```text id="oqnt9h"
delete from users where name = "Sergei"
```

### Информация о таблице — `info`

Команда `info` выводит информацию о структуре таблицы и количестве записей.

Синтаксис:

```text id="n3vjw3"
info <имя_таблицы>
```

Пример:

```text id="l6dnx9"
info users
```

Результат:

```text id="7mrcio"
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 1
```

## Декораторы и дополнительные возможности

В проекте реализованы декораторы для централизованной обработки ошибок, подтверждения опасных операций и измерения времени выполнения функций. Также для операции `select` реализовано кэширование результатов запросов с использованием замыкания.

### Обработка ошибок

Для обработки ошибок используется декоратор `handle_db_errors`.

Декоратор перехватывает исключения, возникающие при работе с базой данных:

- `KeyError` — обращение к несуществующей таблице или столбцу;
- `ValueError` — ошибки валидации данных;
- `FileNotFoundError` — отсутствие необходимого файла.

Благодаря этому обработка ошибок вынесена из функций работы с базой данных в единый декоратор.

Пример ошибки валидации:

```text
>>> insert into users values ("Sergei", "28", true)
Ошибка: Некорректный тип значения для столбца "age". Ожидается int.
```

Пример обращения к несуществующей таблице:

```text
>>> insert into unknown values ("Sergei", 28, true)
Ошибка: Таблица "unknown" не существует.
```

### Подтверждение опасных операций

Для операций удаления используется декоратор `confirm_action`.

Перед выполнением опасной операции программа запрашивает подтверждение пользователя.

Декоратор применяется к:

- `drop_table` — удаление таблицы;
- `delete` — удаление записей.

Пример удаления записи:

```text
>>> delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: n
Операция отменена.
```

Если пользователь вводит `y`, операция выполняется:

```text
>>> delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: y
Запись с ID=1 успешно удалена из таблицы "users".
```

Аналогично работает удаление таблицы:

```text
>>> drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.
```

Любой ответ, кроме `y`, отменяет операцию.

### Измерение времени выполнения

Для измерения времени выполнения операций используется декоратор `log_time`.

Время измеряется с помощью `time.monotonic()`.

Декоратор применяется к операциям `insert` и `select`.

Пример:

```text
>>> insert into users values ("Sergei", 28, true)
Функция insert выполнилась за 0.000 секунд
Запись с ID=1 успешно добавлена в таблицу "users".
```

При выполнении `select`:

```text
>>> select from users
Функция select выполнилась за 0.000 секунд
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+
```

### Кэширование запросов

Для кэширования результатов используется функция `create_cacher()`.

Функция создаёт замыкание, внутри которого хранится словарь с результатами выполненных запросов. При повторном выполнении одинакового `select` сначала выполняется поиск результата в кэше.

Если результат уже существует, он возвращается из кэша. Если результата нет, выполняется запрос, после чего его результат сохраняется в кэш.

Кэширование применяется к операции:

```text
select
```

Это позволяет не выполнять повторную обработку данных для одинаковых запросов.
